# Workshop 1 - Inicio de sesion con PHP

## Descripcion
Aplicacion web sencilla desarrollada en PHP que permite verificar si un usuario existe en una base de datos MySQL.

## Funcionalidades
- Formulario de inicio de sesion.
- Conexion a una base de datos MySQL.
- Consulta para verificar las credenciales del usuario.
- Mensaje de confirmacion cuando el usuario existe.

## Tecnologias utilizadas
- PHP
- MySQL
- HTML
- XAMPP

## Base de datos
Se utiliza la base de datos `workshop1` con una tabla llamada `usuarios`.

## Ejecucion
1. Iniciar Apache y MySQL desde XAMPP.
2. Crear la base de datos `workshop1` y su tabla `usuarios`.
3. Abrir `http://localhost/Workshops/Workshop%201/`.
4. Ingresar las credenciales de un usuario registrado.
